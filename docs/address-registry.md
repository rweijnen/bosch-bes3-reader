## Worked examples

Addresses with a real captured-byte walkthrough, for anything non-obvious about how to decode them.

### DriveUnit.ASSIST_MODE_COLORS (0x180e)

Packed varint repeated uint32 (ArrayOf5Uint32), confirmed against com.bosch.ebike.messagebus.MessageBus$DriveUnit.assistModeColors in Flow decompile. Each uint32 packs R<<24\|G<<16\|B<<8\|A - alpha LAST, not Android's conventional ARGB. Confirmed empirically: every real mode decodes to full alpha (0xff) only with this byte order; the alpha-first reading gave implausible, inconsistent per-mode alpha values instead.

```
raw bytes:  00 ff c1 f8 c5 07 ff b1 97 05 ff db 8f b2 09 ff ab 80 90 0e
decoded:    #000000 (off/walk, alpha=0 = unset), #78be20 (eco), #00a5d8 (tour+), #9643ed (auto), #e20015 (turbo)
```
